# documents/

Put your own documents here. Everything in this folder except this README is ignored by git, so it never ends up in the public repo.

What to put here:

- **Your CV**, as PDF, Word (.docx), Markdown or plain text. Older CVs are welcome too: they often mention things your current one dropped.
- **Your LinkedIn data export** (coming soon): LinkedIn → Settings → Data privacy → Get a copy of your data.
- **Anything else about your work**: reference letters, performance reviews, project write-ups.
- **`writing-samples/`**: things you've written yourself (cover letters, posts, emails), so drafts can sound like you.

Subfolders are fine. Your files stay where you put them. When you import, the tool remembers which files it has read, so running it again only picks up new or changed ones.

Ask your agent to "import my CV", or run `bun run ojs profile import`.
